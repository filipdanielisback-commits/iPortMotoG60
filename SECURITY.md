# Security Policy

## Project status

This repository is currently a documentation and feasibility-research project. It does not publish a bootable image or supported device modification.

## Safe research

- Do not share passwords, access tokens, private keys, or account recovery codes.
- Do not publish device-unique identifiers or personal data in logs.
- Do not experiment with bootloader, partition, or firmware changes on a device you cannot safely recover.
- Preserve the original firmware and understand the recovery procedure before any future device-side testing.
- Treat unverified images and binaries as untrusted.

## Reporting

For security-sensitive issues in this repository, avoid posting secrets or exploit details in public issues. Use GitHub's private vulnerability reporting feature if it is enabled for the repository; otherwise contact the repository maintainers through a private channel.

There are currently no official releases or supported installation instructions.
